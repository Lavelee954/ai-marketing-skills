# Deck Generator Style Presets

Use these presets as starting points. Override any field when the user provides brand guidance.

| Style | Direction | Palette | Texture |
|-------|-----------|---------|---------|
| `whiteboard` | Hand-drawn explanations and simple diagrams | white, black ink, orange accent | marker strokes |
| `corporate` | Executive-ready business presentation | navy, white, gold | clean vector shapes |
| `minimalist` | Sparse high-contrast slides | white, electric blue, charcoal | large whitespace |
| `dark-tech` | Technical architecture or AI/product demos | near-black, neon green, slate | terminal/grid motifs |
| `playful` | Startup or consumer storytelling | pastel mix, warm neutrals | rounded cards |
| `editorial` | Strong narrative and thought leadership | black, white, red accent | magazine layout |

## Prompt Pattern

```text
Create a 16:9 presentation slide in the [style] style.
Title: [title]
Content: [body]
Visual direction: [visual cues]
Constraints: no tiny text, strong hierarchy, safe margins, coherent typography.
```
